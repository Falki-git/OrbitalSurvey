# Mass and Scalar Transformers

This group covers transformers that affect or display simple scalar part values.

## Included transformers

* `MassModifier`
* `PartScalarTransformer`
* `DefaultMassVisualizer`
* `DefaultScalarVisualizer`

## Use Cases

* use `MassModifier` when the variant should change OAB mass directly
* use `PartScalarTransformer` when the variant should emit a saved scalar override for generated part data
* use the `Default*Visualizer` helpers when you want the popout UI to show the part's baseline values for comparison
