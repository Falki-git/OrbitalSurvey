# DefaultMassVisualizer

`DefaultMassVisualizer` displays the stock part mass in the V-SwiFT popup UI.

## Purpose

Use this transformer when you want users to see the unmodified baseline mass before applying one or more `MassModifier` entries. It is a comparison aid, not a behavior-changing transformer.

## Type

Source-backed runtime type: `VSwift.Modules.Transformers.DefaultMassVisualizer`

## Fields

* This transformer has no author-facing data fields

## Behavior

* `ApplyCommon`: no effect
* `ApplyInOab`: no effect
* `ApplyInFlight`: no effect
* Visualization reads `modulePartSwitch.OABPart.AvailablePart.Mass` and formats it as the baseline mass stat block

## State handling

* Reverter: no
* Saves information: no
* Visualizes information: yes

## Example

```patch
Transformers: [
  {
    Name: "DefaultMassVisualizer"
  },
  {
    Name: "MassModifier",
    Modifier: -0.08
  }
]
```

## Caveats

* This transformer is UI-only.
* It reflects the stock available-part mass, not a post-transform recomputation.
* It is most useful when paired with `MassModifier` so the popup presents both baseline and variant delta information together.
