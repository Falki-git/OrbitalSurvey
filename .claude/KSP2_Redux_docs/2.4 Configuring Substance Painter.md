# Configuring Substance Painter


1. Download all files at this location: [https://github.com/KSP2Community/CommunityPartsPack/tree/main/Textures/Community Substance Painter presets](https://github.com/KSP2Community/CommunityPartsPack/tree/main/Textures/Community%20Substance%20Painter%20presets).
2. Make sure the `Kerbal_Space_Program_2_Parts_Paintable.spt` file is in your `Documents/Adobe/Substance Painter/Assets/templates` folder. If the `templates` folder doesn't exist yet, create one under `Assets` and drop that file in it.
3. Use the **File > Import resources...** menu to bring up the Import Resources dialog and click on the **Add Resource** button to bring in the `KSP2_Part.spsm` file. Repeat this step for the `Kerbal Space Program 2 - Standard Damaged.spexp` file. Both of these should go into your library as you're going to need them with every part you make.
4. Use the **Add Resources** button to find the resource you want to import.
5. Select the file and click the **Open** button.
6. Repeat steps 4 and 5 above for as many things as you would like to import.
7. Select the destination to import your resources to. Hint: library `your_assets` for these.
8. Click **Import.**
