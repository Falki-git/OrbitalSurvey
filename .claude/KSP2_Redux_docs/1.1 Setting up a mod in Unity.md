# Setting up a mod in Unity

## 1. Installing Unity


1. Install Unity Hub from <https://unity.com/download>
2. Install Unity version 6000.4.1f1 from <https://unity.com/releases/editor/whats-new/6000.4.1f1>

## 2. Installing the Redux Template (Git Edition)


:::info
Installing the Redux Template requires Git to be installed on your computer. You can install Git for Windows from <https://git-scm.com/install/windows>.

:::


:::info
This guide walks you through creating a repository on GitHub for your mod. If you want to only use it locally and not use GitHub beyond downloading the template, follow [Installing Redux Template (Alternative)](/doc/downloading-redux-template-alternative-R9qa63PdvQ)

:::


1. Make sure that you are signed into GitHub
2. Go to <https://github.com/KSP2Redux/Redux.Template>
3. Click on the green "Use this template" button at the top right of the repository
4. ![](/api/attachments.redirect?id=15647ec4-5bfc-4eec-8daa-2f91210ccf09 " =1386x1094")Fill out a repository name and give it a short description, then select "Create Repository".
5. Clone the resulting repository to your computer using Git, this folder will now be your project folder.

## 3. Setting up the Redux Modding SDK in Unity


1. Open Unity Hub
2. Navigate to Projects, press `Add`, then `Add project from disk`![](/api/attachments.redirect?id=717e0267-6ba4-4a62-935e-697d9134203d " =1583x749")
3. Select your project folder from the previous section
4. Launch the project from Unity


:::warning
Unity will mention Compiler Errors when launching the project, click `Ignore`

:::

## 4. Importing KSP2 Redux into Unity


1. Open Tools > ThunderKit > settings![](/api/attachments.redirect?id=a25281f2-d954-455b-8e49-a1a12d86c507 " =920x381")
2. Go to `ThunderKit Settings` and press `Import`![](/api/attachments.redirect?id=d6f40468-5b6c-4dc8-8bf8-603ed27ae15a " =1259x721")
3. Select `KSP2_x64.exe` from your KSP2 Redux install folder, and click open


:::warning
You must use a version of KSP2 with Redux beta 5 or newer installed

:::


4. Both times it prompts to restart the project, click `Restart Project`, again pressing `Ignore` when it warns about compile errors
5. Now there should be an item in the assets folder named `ImportKsp2ToEditor`, click on it, then click `Execute` in the inspector![](/api/attachments.redirect?id=27c65405-6b4f-4098-a97b-f154c75e489b " =1599x501")
6. In the `Jobs`→`Burst` menu, make sure to __uncheck__ the `Enable Compilation` option\n![](/api/attachments.redirect?id=c7d5febf-aae3-46e6-8bdd-0ce3e05ff2d6 " =348x143")\n
7. You should now have KSP2 Redux imported into your project, to test this, you can open the `boot-ksp` scene then enter play mode in the editor

## 5. Creating a Mod


1. Go to Modding > Create New Mod in the toolbar![](/api/attachments.redirect?id=979c0c91-a243-4ddc-8309-1eafe13be401 " =818x169")
2. Fill out the Mod Id field, it is highly recommended to use `PascalCase` for the ModId, that is: no spaces or special characters, and the first letter of every word being uppercase.
3. If you know that your mod is going to have code, check `Add Code To Mod`, you can always change this later
4. Finally press `Create`, it should create a folder in assets with the Id you gave the mod
5. Navigate to your mod folder, and click on the asset named swinfo, in the inspector fill out `Name`, `Author`, and `Description`![](/api/attachments.redirect?id=b7b40325-1ec5-4c70-8ef2-e5f590bff200 " =1380x928")

## 6. Testing your mod


1. Open up the KSP2 unity tools window by going to Modding > KSP2 Unity Tools in the toolbar![](/api/attachments.redirect?id=1d98774c-2b8c-49bc-8372-4a18a8b63fc1 " =337x154")
2. Click the checkbox next to your mod, then `Test Selected Mods in Editor`, you can also use `Test In Editor` from the swinfo asset for your mod as well
3. When the game boots, you should see your mod in the `Mods` menu

## 7. Deploying

You can either use the KSP2 Unity Tools menu, or the swinfo asset to deploy your mod to a zip file that you can publish anywhere. Click on `Deploy Selected Mods To Zip File` and you will find your built mod in `Deploy/YourModName.zip` in your project root (outside of Assets, so it won't be visible in Unity).

## Adding External Mod Dependencies

Create a `Mods` folder under your `Assets` directory if there isn't one already, and extract any external mod dependencies into folders in there, this functions exactly like KSP2's mod folder.

## Publicizing KSP2 Redux

Sometimes you need to access private members in the game code, this would normally require reflection, but the Redux template provides an alternative, it ships with a script that will make all private members in the imported game code public for access from your code, to invoke this script go to Modding > Publicize Assembly-CSharp.dll.
