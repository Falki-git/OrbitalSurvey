# Getting Started

This set of documents is meant to get you up to speed with patch manager, getting you from nothing to your first patch.

It is highly recommended for you to read this in order if you are new to patching. :3

* [What is PatchManager](/doc/what-is-patchmanager-JqQGaCKJnC) explains the model: patches change the game's JSON assets as they load, so you tweak data instead of editing the game.
* [How the game's content is organized](/doc/how-the-games-content-is-organized-wvROpWTIgy) is the small vocabulary (assets, addresses, labels) the rest of the docs assume, plus how to find a real asset id.
* [Setting up your editor](/doc/setting-up-your-editor-UScg880clw) installs the PatchManager Lua extension so you get autocomplete and inline docs for the whole `PM` and `J` surface.
* [Your first patch](/doc/your-first-patch-2TTZEeDRtk) walks through a small, real patch line by line.
* [File layout and discovery](/doc/file-layout-and-discovery-vYcsLN5rtw) explains where patch files go, how the game finds them, and what `ModId` and `Location` are.
* [Shipping patches](/doc/shipping-patches-8EnGXsVNKP) covers packaging patches in a mod so other people can install them.
