# Attach Node Transformers

This group covers transformers that create or reposition attach nodes.

## Included transformers

* `AttachNodeAdder`
* `AttachNodeMover`

## Use Cases

* use `AttachNodeAdder` when the variant should add new dynamic nodes or override existing nodes by `nodeID`
* use `AttachNodeMover` when the node already exists and you only need to move it in OAB

## Related topic

If the node should exist independently of variant selection, prefer `PredefinedDynamicNodes` on `Data_PartSwitch` instead of a transformer.
