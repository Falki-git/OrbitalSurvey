# TextVisualizer

`TextVisualizer` adds a localized informational stat block to the V-SwiFT popup UI without changing part behavior.

## Purpose

Use this transformer when a variant needs explanatory text in the UI, such as a warning, a flavor note, or a short description of a feature toggle that is not obvious from the raw stats.

## Type

Source-backed runtime type: `VSwift.Modules.Transformers.TextVisualizer`

## Fields

* `TitleKey`: `string`
* `DescriptionKey`: `string`

## Behavior

* `ApplyCommon`: no effect
* `ApplyInOab`: no effect
* `ApplyInFlight`: no effect
* Visualization resolves both localization keys and creates a stat block from the resulting strings

## State handling

* Reverter: no
* Saves information: no
* Visualizes information: yes

## Example

```patch
Transformers: [
  {
    Name: "TextVisualizer",
    TitleKey: "MyMod/VSwift/Variant/Title",
    DescriptionKey: "MyMod/VSwift/Variant/Description"
  }
]
```

## Caveats

* This transformer is UI-only.
* If a localization key is missing, the raw key string may appear instead of translated text.
* Use it to supplement behavior-changing transformers, not to replace them.
