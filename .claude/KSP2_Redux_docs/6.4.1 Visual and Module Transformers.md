# Visual and Module Transformers

This group covers transforms that affect meshes, materials, module data, and informational UI.

## Included transformers

* `MaterialSwapper`
* `ModuleDefinitionTransformer`
* `TransformActivator`
* `TextVisualizer`

## Use Cases

* use `TransformActivator` for on/off mesh visibility
* use `MaterialSwapper` for material-property swaps
* use `ModuleDefinitionTransformer` when you need to target one field on another part module's data object
* use `TextVisualizer` when you only want to show variant-specific text in the popout UI
