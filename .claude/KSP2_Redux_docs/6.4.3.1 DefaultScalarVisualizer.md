# DefaultScalarVisualizer

`DefaultScalarVisualizer` shows the stock value of a supported part-data scalar in the V-SwiFT popup UI.

## Purpose

Use this transformer when you want the popup to show the base value of a scalar that a `PartScalarTransformer` may later override. It is the scalar equivalent of `DefaultMassVisualizer` and `DefaultEngineModesVisualizer`.

## Type

Source-backed runtime type: `VSwift.Modules.Transformers.DefaultScalarVisualizer`

## Fields

* `Key`: `string`

## Behavior

* `ApplyCommon`: no effect
* `ApplyInOab`: no effect
* `ApplyInFlight`: no effect
* Visualization reflects over the base part-data object, reads the named field, and renders a stat block when the key is supported by `PartScalarTransformer.Visualizers`

## State handling

* Reverter: no
* Saves information: no
* Visualizes information: yes

## Example

```patch
Transformers: [
  {
    Name: "DefaultScalarVisualizer",
    Key: "maxTemp"
  },
  {
    Name: "PartScalarTransformer",
    Key: "maxTemp",
    Value: 2400
  }
]
```

## Caveats

* This transformer does not change data; it only renders baseline UI.
* If `Key` is not both present on the base part-data object and registered in the V-SwiFT visualizer table, the result is effectively empty.
* It is most useful when paired with `PartScalarTransformer`.
