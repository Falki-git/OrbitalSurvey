# Worked transformer examples

This page collects short V-SwiFT transformer examples.

## Activate transforms

```patch
+OpenFrame {
    +TransformActivator {
        Transforms: [
            FrameA,
            FrameB
        ];
    }
}
```

## Add dynamic nodes

```patch
+RadialOptions {
    +AttachNodeAdder {
        Nodes: [
            {
                nodeID: radial_mount,
                size: 1,
                position: { x: 0.5, y: 0, z: 0 },
                orientation: { x: 1, y: 0, z: 0 }
            }
        ];
    }
}
```

## Save a scalar override

```patch
+HeatShielded {
    +PartScalarTransformer {
        Key: maxTemp;
        Value: 2200;
    }
    +DefaultScalarVisualizer {
        Key: maxTemp;
    }
}
```

## Add resource containers

```patch
+Hydrogen {
    +ResourceContainerAdder {
        Containers: [ /* contained resource definitions */ ];
    }
}
```

## Notes

These examples are intentionally short. Use them as structure templates, then fill in the full game data objects required by your actual part and transformer choice.
