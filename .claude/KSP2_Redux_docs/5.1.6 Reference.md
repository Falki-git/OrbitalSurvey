# Reference

Lookup material. These pages are for checking a name or a value, not for reading start to finish.

* [LuaPatch cheat sheet](/doc/luapatch-cheat-sheet-9nuhawbJ9f) lists every method in the patch chain (`:Named`, `:Needs`, `:Requires`, `:Early`, and the rest) with a one-line description, grouped by what it does.
* [Enums](/doc/enums-HzbEUWmcgY) lists the named value sets you will run into in part, science, and resource fields (engine types, part categories, resource flow modes, and so on).
* [Glossary](/doc/glossary-qwuDlWEZgm) defines the terms the docs use: label, address, converter, pass, bucket, namespaced id, summary, and more.

For the full field list of any asset, use the `.d.lua` stubs through autocomplete rather than a written table. See [Setting up your editor](/doc/setting-up-your-editor-UScg880clw).
