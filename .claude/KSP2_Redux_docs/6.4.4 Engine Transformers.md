# Engine Transformers

This group covers engine-related transformers and visualizers.

## Included transformers

* `EngineModeSwapper`
* `DefaultEngineModesVisualizer`

## Use Cases

* use `EngineModeSwapper` when the variant should replace selected `Data_Engine.EngineMode` definitions by `engineID`
* use `DefaultEngineModesVisualizer` when the variant should only show the part's existing engine-mode stats in the V-SwiFT popout UI
