# Transformer reference

This section documents the V-SwiFT transformer classes that variants use to change live part behavior or generate saved override data.

## Transformer contract

All transformer classes implement `ITransformer` and expose the same core surface:

* `ApplyCommon(Module_PartSwitch)`
* `ApplyInOab(Module_PartSwitch)`
* `ApplyInFlight(Module_PartSwitch)`
* `Reverter`
* `SavesInformation`
* `VisualizesInformation`

## How to think about the phases

* `ApplyCommon` changes the live part object in both OAB and flight contexts.
* `ApplyInOab` applies changes that only make sense in the editor state.
* `ApplyInFlight` is reserved for flight-time behavior, though many current transformers leave it empty.

## Saved-information transformers

Some transformers do not mutate the live OAB part directly. Instead they emit saved override data through `SaveInformation()`, and that data is later replayed into generated `PartCore` data by V-SwiFT persistence hooks.

## Visualized transformers

Transformers with `VisualizesInformation = true` are intended to contribute information blocks to the V-SwiFT popout UI. In the current codebase, some transformers set this flag but do not yet provide a custom visualizer method, so treat the runtime UI support as implementation-specific rather than guaranteed.
