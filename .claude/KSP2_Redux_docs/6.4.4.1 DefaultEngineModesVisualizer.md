# DefaultEngineModesVisualizer

`DefaultEngineModesVisualizer` shows the baseline engine-mode stats from the stock part, without changing the part at all.

## Purpose

Use this transformer when you want the V-SwiFT popup UI to show the part's original engine information alongside variant-specific engine swaps. It is best paired with `EngineModeSwapper` so users can compare the default and replacement modes in the same UI surface.

## Type

Source-backed runtime type: `VSwift.Modules.Transformers.DefaultEngineModesVisualizer`

## Fields

* This transformer has no author-facing data fields

## Behavior

* `ApplyCommon`: no effect
* `ApplyInOab`: no effect
* `ApplyInFlight`: no effect
* Visualization reads the stock `Data_Engine` from the original part definition and produces the same style of propellant, thrust, and ISP stat blocks used by `EngineModeSwapper`

## State handling

* Reverter: no
* Saves information: no
* Visualizes information: yes

## Example

```patch
Transformers: [
  {
    Name: "DefaultEngineModesVisualizer"
  },
  {
    Name: "EngineModeSwapper",
    Modes: [
      {
        engineID: "main",
        EngineDisplayName: "MyMod/VSwift/EngineMode/Vacuum"
      }
    ]
  }
]
```

## Caveats

* This transformer is UI-only. It never changes engine behavior.
* It only produces output when the part actually has a `Module_Engine` / `Data_Engine` pair to inspect.
* Because it compares against the stock part core, it is most useful when your variant keeps the same general engine layout and only changes specific mode data.
