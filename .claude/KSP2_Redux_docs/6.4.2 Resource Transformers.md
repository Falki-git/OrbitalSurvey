# Resource Transformers

This group covers transformers that alter resource-container data.

## Included transformers

* `ResourceContainerAdder`
* `ResourceContainerRemover`

## Use Cases

* use `ResourceContainerAdder` to append new contained-resource definitions
* use `ResourceContainerRemover` to filter named resources out of existing containers

## Notes

Both transformers save information for later replay into generated part data, and both rely on `ResourceContainerReverter` to restore the original OAB state before a different variant is reapplied.
