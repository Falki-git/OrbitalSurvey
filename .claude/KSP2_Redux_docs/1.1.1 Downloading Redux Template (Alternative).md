# Downloading Redux Template (Alternative)

:::info
Even though this does not go through Git for most steps, using the Redux Template still requires Git in order to download dependencies. You can download Git for Windows from [https://git-scm.com/install/windows.](https://git-scm.com/install/windows)

:::


1. Go to <https://github.com/KSP2Redux/Redux.Template>.
2. Click on "Code", then "Download ZIP".![](/api/attachments.redirect?id=ee4b5505-d070-4269-8c10-b81c5a842b3b " =1267x1133")\n
3. Extract the zip file into any folder. This will become your project folder for the next steps.
4. Continue following [Setting Up the Redux Modding SDK](/doc/getting-started-with-modding-IqYVHCZ79Z) from step 3.
