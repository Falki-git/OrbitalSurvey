# TransformActivator

`TransformActivator` enables named child transforms on the instantiated part hierarchy.

## Purpose

Use this transformer when a variant should reveal a mesh, prop, or other child object that already exists under the part prefab. It is a good fit for simple visual toggles where the transform is already authored and only needs to be activated.

## Type

Source-backed runtime type: `VSwift.Modules.Transformers.TransformActivator`

## Fields

* `Transforms`: `List<string>`
* Each string is a child-transform name searched recursively under the part root

## Behavior

* `ApplyCommon`: recursively finds each named transform and sets the corresponding `GameObject` active
* `ApplyInOab`: no effect
* `ApplyInFlight`: no effect

## State handling

* Reverter: yes, via `TransformReverter.Instance`
* Saves information: no
* Visualizes information: no

## Example

```patch
Transformers: [
  {
    Name: "TransformActivator",
    Transforms: ["variant_mesh", "secondary_fairing"]
  }
]
```

## Caveats

* The target transform must already exist in the prefab hierarchy.
* This transformer activates objects; it does not create new transforms or edit meshes.
* Missing transform names are logged as errors by the runtime.
