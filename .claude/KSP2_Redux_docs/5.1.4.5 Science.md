# Science

`PM.Science` covers the science and progression systems: experiments, the science regions that classify where you are, the discoverables you find in the world, and the tech tree that spends science points to unlock parts. It is a moderate-sized module with a separate entry point per content kind.

## The entry points

Science is several different assets, so there is a `Patch` method per kind rather than one:

* `PM.Science:PatchExperiments(name)` patches science experiments.
* `PM.Science:NewExperiment(name, callback)` creates a new experiment.
* `PM.Science:PatchRegions(name)` patches science regions.
* `PM.Science:PatchDiscoverables(name)` patches discoverables.
* `PM.Science:PatchTechNodes(name)` patches tech-tree nodes.
* `PM.Science:AddPartsToTechNode(nodeName, ...)` is a shortcut for unlocking parts.

## Experiments

`PatchExperiments` targets an experiment by id. A common edit is appending a flavor description for a location the experiment was missing. This real patch fixes a gap on Pol:

```lua
PM.Science:PatchExperiments("CrewObservationPolMidlandsFlavorFix")
          :Named("CrewObservation")
          :Do(function(experiment)
              experiment.DataFlavorDescriptions:Append({
                  ResearchLocationID = "Pol_Landed_PolMidlands",
                  LocalizationTag = "Science/Experiments/CrewObservation/Data/Flavor/Pol_Landed_PolMidlands"
              })
          end)
```

`NewExperiment(name, callback)` creates a whole new experiment, filling in its data and sample values, descriptions, and transmission size.

## The tech tree

Tech nodes are where most science patches land, because reorganizing the tree and moving part unlocks is common. `PatchTechNodes` targets a node by id (`tNode_2v_rockets_01` and so on). Inside, you edit the node's prerequisites, science cost, position, and unlocked parts. This real patch fully reworks a node

```lua
PM.Science:PatchTechNodes("2VRockets01Reorder")
          :Named("tNode_2v_rockets_01")
          :Do(function(node)
              node.RequiredTechNodeIDs = { "tNode_1.5v_rockets_02" }
              node.RequiredSciencePoints = 230
              node.UnlockedPartsIDs:RemoveWhere(|id| id == "booster_1v_solid_kickback")
              node.UnlockedPartsIDs:Append("adapter_2v_methalox_1.5v-2v")
              node.TierToUnlock = 0
              node.TechTreePosition = { x = 1600.0, y = 750.0 }
          end)
```

Note the list operations on `UnlockedPartsIDs`: `:RemoveWhere` to drop a part, `:Append` to add one, or a whole-list assignment to replace it. These are the [JSON list methods](/doc/working-with-json-fWfY8KrejF).

## Unlocking parts the easy way

Adding parts to a node is so common it has a dedicated shortcut. `AddPartsToTechNode` takes the node id and any number of part ids, and appends them to that node's unlock list:

```lua
PM.Science:AddPartsToTechNode("tNode_1v_rockets_02",
    "booster_0v_srb_mantis",
    "booster_0v_srb_shrimp")
```

This is equivalent to a `PatchTechNodes` that appends to `UnlockedPartsIDs`, just shorter. Use it when all you are doing is unlocking parts.

## Regions and discoverables

`PatchRegions` patches science regions, the zones that set the per-situation science multipliers for a body. `PatchDiscoverables` patches discoverables, the anomalies you find in the world, keyed by region id with a position and detection radius. Both are indexed lists, so you reach an entry by its id and edit it. Their field forms are in `pm-science.d.lua`.
