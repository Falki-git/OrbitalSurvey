# Sounds for parts with Wwise and Unity

### Prerequisites

[Setting up a mod in Unity](/doc/e361c8c3-8fe1-42e6-9596-fb789b913fe0) 

### Step 1: Wwise installation


1. You need to create an Audiokinetic account: <https://www.audiokinetic.com/fr/products/wwise/>
2. Next, install Wwise Launcher

Wwise is free for a 200 sounds databank.


:::warning
**Ok, now a warning :**

*When I started my mod, I couldn't get the sound to work with the latest 2023 version of Wwise.*

*I continued to use version 2021 of Wwise to prepare my sounds and I integrated version 2023 of the Wwise libraries into Unity for maximum compatibility.*

*I will explain how I did it but maybe you can try directly with the latest 2023 versions. If you succeed, let me know so that I can modify this tutorial.*

*So, this tutorial will first install version 2021 to be able to have a Wwise project in 2021 format then I update the Wwise libraries in Unity in 2023 format.*

:::

### Step 2: Wwise project

You need to create your sound databank:

 ![](/api/attachments.redirect?id=3c1b41c5-e3fa-43c5-b1dc-4bcd0b240171 " =732x682")

 ![](/api/attachments.redirect?id=e3a7d1ba-1720-4a1a-a729-03bdb654326c " =422x351")

I'm only using windows platform and English language but you can add/remove/modify:

 ![](/api/attachments.redirect?id=cb70d3db-69ac-4cb9-bf76-dd23afd72e34 " =300x324")

 ![](/api/attachments.redirect?id=d1617d0c-d161-4319-bf63-2e2efcb57845 " =300x322")

Next step: importing your audio files. I'm using `.wav` format.

 ![](/api/attachments.redirect?id=b854bbaa-720a-4e83-bdfe-29ed8f736787 " =467x787")


Select the .wav file on your computer.

 ![](/api/attachments.redirect?id=6e1f3641-2004-4919-97d6-36fb54145a91 " =514x311")

Then, import:

 ![](/api/attachments.redirect?id=f223433e-2e8e-4a49-82a0-bcb0faa2e130 " =556x335")

 ![](/api/attachments.redirect?id=75dcb6aa-031f-488b-8e5b-45a72104aa4b " =438x539")

You can double click on you audio (for example if you want to set a loop):

 ![](/api/attachments.redirect?id=10466813-769b-4ae4-bfa0-c6d8d82004a6 " =1028x554")

Now, you have to set events with your audio for using in Unity - one for playing it, one for stopping it:

 ![](/api/attachments.redirect?id=17aa09d2-a72d-4f15-8000-e19efab69a14 " =657x712")

Click on your new event for setting it:

 ![](/api/attachments.redirect?id=7c250999-cbf1-4a49-9221-28287f6603f5 " =642x314")

Right click on Target field for assign an audio to this event:

 ![](/api/attachments.redirect?id=16e39aba-5d12-4401-b9cc-e050d6d5bd3f " =642x304")

Select your audio:

 ![](/api/attachments.redirect?id=466f4312-50f5-4019-aab6-0f8e53fec21b " =549x581")

Same event creation for stopping audio action:

 ![](/api/attachments.redirect?id=09ae6df8-14a5-4e2b-b26a-8c0614c2e554 " =1037x509")

Same for playing, assign your audio to this event.

Now both events appear on the list:

 ![](/api/attachments.redirect?id=01e07e8f-fd53-46be-959a-4de2e4997fc3 " =1466x912")

To finish, you must assign new events to your soundbank. For that, select your soundbank and drag and drop your events on the bottom window:

 ![](/api/attachments.redirect?id=846b9cdb-7379-43ef-8ff0-f1f758cfdc8e " =872x1024")

Ok, ready now.

Now, just generate your soundbank for using it with Unity and your final mod:

 ![](/api/attachments.redirect?id=f7f31020-1c70-401d-b9af-542f6f340593 " =1920x1028")

 ![](/api/attachments.redirect?id=f612b8e2-0f2e-4698-b3e8-6461d8c26e52 " =1457x775")

Your soundbank is now in your Wwise folder `<Wwise Project>/GeneratedSoundBanks/Windows`

You have to copy the file `.bnk` in your KSP2 mod folder `<Your Mod>/assets/soundbanks/`

Now, keep your Wwise Project open and start Unity.

### Step 3: Unity project

Normally, both are connected. We will verify in the Wwise picker window:

 ![](/api/attachments.redirect?id=c9d94683-df2d-47ec-a1ab-e3a84b302eb5 " =653x473")

All your soundbank events normaly appear on this window.

I will show you 2 ways for using them.

#### Example 1 : add an engine sound

First, I create an empty gameobject for sound: `u_amb_Engine`

 ![](/api/attachments.redirect?id=45c6e5b0-d794-435d-8c3f-6e46b6b2e946 " =935x553")

And on it few Components:

 ![](/api/attachments.redirect?id=ad057d8d-d66f-4d8c-a564-0387d5766a50 " =687x539")

**In Rigidbody, check "Is Kinematic" and uncheck "Use Gravity" !**

Next, add audio Components:

 ![](/api/attachments.redirect?id=1b7d9d93-cc7e-437b-a27d-68db51141158 " =684x190")

 ![](/api/attachments.redirect?id=adc7e645-8c4d-44b6-a491-0626f5901a1f " =679x190")

For RTPC mapping, I've created AllRTPC:

 ![](/api/attachments.redirect?id=e69e2cd1-7283-4d10-abec-d54a2292308a " =914x315")

And for your engine audio:

 ![](/api/attachments.redirect?id=a22dff85-0289-46bf-a743-d3d7b9048615 " =681x423")

I've select 2 events for playing and stopping my engine sound : `engine3_play` & `engine3_stop`

That's all. Now your engine will have sound !!!

#### Example 2 : sound in animation

For this example, I will show a solar panel with animations for deploying and retracting.

First, I create an empty gameobject `u_amb_audio_solar_arrays`

 ![](/api/attachments.redirect?id=fb685a3d-7de5-4e01-af19-be5a8faa9ca8 " =1157x739")

I've add components on it:

 ![](/api/attachments.redirect?id=500c32b1-bc7d-47fd-a8ba-5f306d4b3252 " =450x497")

**In Rigidbody, check "Is Kinematic" and uncheck "Use Gravity" !**

On the gameobject with Animator component:

 ![](/api/attachments.redirect?id=b91e175d-98bd-434e-8c9e-49e5910b4442 " =451x690")

Drag & drop your `u_amb_audio_solar_arrays` gameobject in Animation Events Object field.

Then, we can set audio in animations, on deploying and retracting.

On the first timeline, in your animation windows, on the first frame, right click:

 ![](/api/attachments.redirect?id=a7dbd7d8-3f77-4fda-a2a0-32def82f66e1 " =799x315")

And set in Inspector:

 ![](/api/attachments.redirect?id=1a7aa0c9-4205-4591-9b4a-c86cfc764a4e " =451x243")

Same action for the last animation frame:

 ![](/api/attachments.redirect?id=4806f6d4-f405-45eb-803a-e787a7a98365 " =447x204")

Now, my animation has 2 audio events (white rectangles), in the first frame to start the sound, in the last frame to stop it:

 ![](/api/attachments.redirect?id=d91539a0-13bb-486b-9ad3-8daa9e3a13b1 " =1439x228")
