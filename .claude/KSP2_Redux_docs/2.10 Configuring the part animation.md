# Configuring the part animation

1. In the Project window, click on the imported FBX object.
2. In the Inspector window, click on the Animation tab.
3. Set `Anim. Compression` to Off.
4. Split the animation into four states in the `Clips` list: `retracted`, `deploy`, `deployed` and `retract`.
   * The retracted and deployed states are a single frame.
   * You should prefix these states with the part name to avoid confusion if multiple parts of the mod contain animation.

 ![](/api/attachments.redirect?id=139ab758-9737-46e4-9e4d-4cede2202016 " =300x436")


5. Drop the part under `model` and unpack it completely.\n![](/api/attachments.redirect?id=f74ace73-7acf-4844-ac43-48afb3e49cda " =300x376")
6. In the Part folder, create an Animation Controller.

   ![](/api/attachments.redirect?id=00e48b24-3a80-4af1-95b4-917ad68c1afe " =385x280")
7. Double-click on the controller to open the Animator tab.
8. Drag the four states into the Animator tab.
   * Start with retracted so that it automatically links to Entry, then the other three.\n![](/api/attachments.redirect?id=63c74189-9856-4a73-a568-0bd8e1b76cc6 " =428x224")
9. In the Animator Parameters tab, create:
   * a boolean `isDeployed`,
   * a trigger `reverseAnimStateChange`,
   * a float `playbackMul` with a value of 10.

 ![](/api/attachments.redirect?id=e92695d0-e98f-42ca-9517-40d08f63ca7a " =428x251")


10. Create the transitions between states:
    * entry → retracted,
    * retracted ↔ deploy,
    * deploy → deployed,
    * deployed ↔ retract,
    * retract → retracted.

 ![](/api/attachments.redirect?id=8bb47f21-541e-4326-8545-46f1f52d84e3 " =385x302")


11. Click on the transition from retracted to deploy:
    * set `Exit Time` to 0,
    * uncheck `Has Exit Time`,
    * uncheck `Fixed Duration` (in Settings),
    * set `Transition Duration` to 0,
    * add the boolean `isDeployed` = True to the list of conditions,
    * check the animation by playing it in the preview window.

 ![](/api/attachments.redirect?id=57806531-f1f5-4767-9f2d-9ca056ea30a4 " =428x196")


12. Perform the same operation on the transition from deployed to retract, except that `isDeployed` = False.
13. Click on the transition from deploy to retracted:
    * set `Exit Time` to 0,
    * set `Transition Duration` to 0,
    * add the `reverseAnimStateChange` trigger to the list of conditions.

 ![](/api/attachments.redirect?id=e42ffbbf-3383-493e-9fd7-65e7f2e93830 " =385x173")


14. Perform the same operation on the transition from retract to deployed.
15. Click on the retracted state: Add the `Module_Anim State Informer` module.
16. Perform the same operation on deployed.
17. Click on the transition from deploy to deployed:
    * set `Exit Time` to 0.99,
    * set `Transition Duration` to 0.01.
18. Perform the same operation on the transition from retract to retracted.
19. Click on each state and in `Speed` > `Multiplier`, select `Parameter`. It should automatically display `playbackMul` in the dropdown. This is for playing the animation ten times faster in the VAB.
20. ![](/api/attachments.redirect?id=c1c0aca8-50a0-426c-a2d3-446b6e74c390 " =300x325")
21. On the mesh, add the `Animator` module and select the controller under `Controller`.

 ![](/api/attachments.redirect?id=c519597f-04a1-4bbe-916f-fbc6d25d3374 " =728x238")


21. On the root part, click `Add Component` → `Module_Deployable`. Set `Animator` to the mesh.
